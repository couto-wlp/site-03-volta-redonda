# DiskCaçamba - Plataforma de Aluguel de Caçambas

Este é um projeto web moderno, focado em alta conversão e otimização para SEO Local, desenvolvido para empresas de locação de caçambas estacionárias. O sistema entrega uma interface profissional, ágil e focada em resultados.

## 🚀 Status do Projeto
**Pronto para Produção (Ready for Deploy)**

## 🛠 Tecnologias Utilizadas
- **Astro 4.x**: Framework de alta performance para sites orientados a conteúdo.
- **Tailwind CSS**: Estilização utilitária de ponta, permitindo layouts robustos e responsivos.
- **Content Collections**: Gerenciamento de conteúdo seguro e tipado para Serviços e Blog.
- **Integração Vercel**: Configurado como Server Side Rendering (SSR) e preparado para deploy imediato.
- **Integração Sitemap**: Geração automática de sitemaps (`@astrojs/sitemap`).

## ✨ Destaques de UX e SEO (Polimento Final)
1. **Design de Elite**: Layout projetado com os padrões mais altos de UI (respiros amplos, sombras coloridas, escala universal).
2. **Alta Performance**: Nota máxima garantida devido ao uso mínimo de JavaScript no lado do cliente.
3. **SEO Local (Schema.org)**: Inclui tags `JSON-LD LocalBusiness` nativas para ranqueamento otimizado no Google Maps.
4. **Cérebro Central (`config.ts`)**: Toda a informação estratégica (NAP - Name, Address, Phone) é consumida a partir de um único arquivo.
5. **Conversão WhatsApp**: Botão flutuante animado altamente visível e interativo.

## 📦 Como executar localmente
1. Instale as dependências: `npm install`
2. Inicie o servidor: `npm run dev`
3. Acesse `http://localhost:4321`

## ⚙️ Deploy
Este repositório está integrado e pronto para deploy através da [Vercel](https://vercel.com). O adaptador `@astrojs/vercel` já está configurado.
